# v1.2.0
- New **Record** button: click it, hold any keys together (e.g. Ctrl+Alt+K), release, and the combo is filled in for you. You can still type keys by hand.

# v1.1.0
- New: **Send to** option per rule. "Real keyboard" sends an actual OS-level key press, so other programs like Discord (mute / deafen / push-to-talk keybinds) can react to it. Works on Windows and macOS.
- macOS: the first real key press asks for **Accessibility** permission (System Settings > Privacy & Security > Accessibility).
- Fixed the pause menu button showing a pink/black missing texture.
- The Help window is now compact.
